# ✅ Problem Statement:

Build a multimodal AI app using Google Gemini 1.5 Flash API that takes an image + a user prompt (text) and returns a relevant hybrid response like:

Captioning the image

Answering a question about the image

Summarizing visual contents

Describing scene elements (e.g., objects, colors, count, etc.)

# ✅ Features Added:

Multiple image uploads 🖼️🖼️

Voice-to-text support using speech_recognition 🎙️
